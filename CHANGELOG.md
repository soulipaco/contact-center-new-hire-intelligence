# Changelog

All notable changes will be documented here. The project follows semantic versioning.

## Unreleased

### Added

- Demo and customer operating modes.
- Canonical observation, agent, target, and training-class contracts.
- Configuration validation and customer adapter generation.
- Namespace-rendered deployable repository builds.
- Feature-aware optional bundle resources.
- Nine-page dashboard with learning, volume, regression, process-control, outlier,
  forecast, action, cohort, and agent analysis.
- Independent fictional-customer fixture and clean-room customer-mode deployment proof.
- Isolated customer model schema and project-specific MLflow experiment paths.
- Direction-aware `below_1_sigma` semantic flag and equivalent-field benchmark gates.
- Direct-engine native Genie deployment with a convergent post-deploy plan.

### Fixed

- Serverless NumPy/Pandas/PyArrow compatibility through bounded job dependencies.
- Customer builds no longer require source-only example fixtures during validation.
- Dashboard and Genie labels no longer describe customer data as synthetic or fictional.
