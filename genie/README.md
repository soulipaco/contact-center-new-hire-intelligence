# Genie semantic module

- `config/` identifies the room and routes its source assets.
- `context/` documents domain rules and table-selection knowledge.
- `source/instruction_library/` is the canonical instruction corpus.
- `source/instructions/` is the active surface generated by
  `scripts/genie/materialize.py`.
- `source/data_sources/` and `source/metadata/` define the five governed views.
- `source/benchmarks/` contains 12 ground-truth questions and SQL references.
- `serialized/` contains the native bundle-deployable `.geniespace.json` artifact.

Never edit `serialized/` by hand; regenerate it with
`python scripts/genie/build_space.py`.
